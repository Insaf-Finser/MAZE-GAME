## Description

Maze Explorer is a mobile 3D maze adventure game built with Unity. The game generates a unique random maze each time a level starts, ensuring a different experience on every playthrough. Players navigate the maze using an on-screen joystick while exploring hidden paths and searching for the exit.

 A dynamic fog-of-war system limits visibility to the area around the player, creating a sense of discovery and suspense. As players move through the maze, previously visited areas remain revealed, helping them track their progress. A minimap assists navigation through increasingly larger and more complex mazes.

 The game features procedurally generated random mazes, mobile joystick controls, 3D isometric gameplay, a fog-of-war exploration system, exploration memory, and minimap navigation. The project focuses on exploration, navigation, and procedural content generation to create an engaging and replayable maze-solving experience.

 The game is built using Unity, with a mix of C#, HTML, and Wolfram Language. The repository contains a variety of assets, including input system actions, joystick packs, and example scenes.
